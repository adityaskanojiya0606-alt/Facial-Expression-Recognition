# Facial Expression Recognition

Facial Expression Recognition using Deep Learning.

## Project Overview

This project aims to recognize human facial expressions from images or webcam input using a Deep Learning model.

## Objective

The main objective is to classify facial expressions into 7 emotion classes:

1. Angry
2. Disgust
3. Fear
4. Happy
5. Sad
6. Surprise
7. Neutral

## Technologies Used

- Python
- PyTorch
- OpenCV
- NumPy
- Matplotlib
- Deep Learning / CNN
